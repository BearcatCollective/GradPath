# Project Topic Area

---
A scheduler for UC students that uses a degree audit and UC's
course catalog to automatically create the fastest possible graduation plan. 
It considers course prerequisites and semester availability, while allowing students to add, remove, or edit classes and see plans for additional majors or minors.
